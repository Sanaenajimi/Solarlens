Architecture

Input (224 × 224 × 3)
  ↓ ResNet-50 backbone — pré-entraîné ImageNet, couches 1-3 gelées
  ↓ Squeeze-Excitation attention — ratio de réduction 16
  ↓ Global Average Pooling
  ↓ Dropout (0.4) → FC (2048 → 512) → ReLU → BatchNorm
  ↓ Dropout (0.3) → FC (512 → 6)
Softmax sur 6 classes

Pipeline de déploiement

PyTorch (.pth) → export ONNX (opset 17) → GitHub Release
  ↓
Navigateur : fetch() du modèle → ONNX Runtime Web (WASM) → inférence locale
  ↓
Aucune image envoyée à un serveur. Tout reste sur l'appareil de l'utilisateur.
